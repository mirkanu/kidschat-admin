  <name>Task 1: Create cost estimation library</name>
  <files>src/lib/cost-estimates.ts, src/lib/__tests__/cost-estimates.test.ts</files>
  <behavior>
    - estimateCost({ haikuMessages, sonnetMessages, avgInputChars, avgOutputChars }) returns { haikuCost, sonnetCost, totalCost } in USD
    - Haiku pricing: $1 input / $5 output per million tokens
    - Sonnet pricing: $3 input / $15 output per million tokens
    - Token estimate: chars / 4 (standard approximation)
    - System prompt tokens (~400) added to input on every message
    - Default avgInputChars=400, avgOutputChars=600 if not provided
    - Zero messages returns zero cost
    - Cost values are numbers (not formatted strings)
  </behavior>
  <action>
    Create `src/lib/cost-estimates.ts` with:

    1. Export `PRICING` constant object:
       ```
       HAIKU_INPUT_PER_MTOK = 1.00
       HAIKU_OUTPUT_PER_MTOK = 5.00
       SONNET_INPUT_PER_MTOK = 3.00
       SONNET_OUTPUT_PER_MTOK = 15.00
       SYSTEM_PROMPT_TOKENS = 400
       DEFAULT_AVG_INPUT_CHARS = 400
       DEFAULT_AVG_OUTPUT_CHARS = 600
       ```

    2. Export `CostEstimate` interface: `{ haikuCost: number; sonnetCost: number; totalCost: number }`

    3. Export `estimateCost(params)` function:
       - For each model, calculate:
         - inputTokens = (SYSTEM_PROMPT_TOKENS + avgInputChars / 4) * messageCount
         - outputTokens = (avgOutputChars / 4) * messageCount
         - cost = (inputTokens * inputRate + outputTokens * outputRate) / 1_000_000
       - Return `{ haikuCost, sonnetCost, totalCost: haikuCost + sonnetCost }`

    4. Export `formatUSD(amount: number): string` — formats to 2-4 decimal places depending on magnitude (e.g., $0.0012, $1.23)

    Write tests first (RED), then implement (GREEN).
  </action>

  </verify>
  <done>estimateCost returns correct costs for known inputs; zero messages returns zero; formatUSD produces readable strings</done>
