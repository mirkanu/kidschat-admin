
For sections 1-3, create async server components that fetch data and pass to client components:
- `SafetyStatusSection` — calls `getSystemStatus()`, passes result to `<SafetyStatusCard>`
- `DigestSection` — calls `get24hDigest()`, passes result to `<ActivityDigestCard>`  
- `AlertsSection` — calls `getRecentAlerts(5)`, passes result to `<RecentAlertsCard>`

Section 4 (Quick Links) is static — render directly in the page component, no data fetch needed.

**page-client.tsx (client components):**
Replace the current `DashboardStats` component entirely. Create three "use client" components:

**`SafetyStatusCard`** (TRUST-01):
- Props: `{ status: SystemStatus }`
- Large card with green ShieldCheck icon and "All Systems Active" text when `allSystemsActive` is true (or yellow AlertTriangle + "Attention Required" if false)
- Below: "Last checked: {relative time}" (e.g., "just now") using the `lastChecked` timestamp
- List each system with a colored dot indicator: green for active, yellow for degraded, red for down
- Use shadcn Card component. Green-tinted background when all active (`bg-green-50 dark:bg-green-950/20 border-green-200 dark:border-green-900`)

**`ActivityDigestCard`** (TRUST-02):
- Props: `{ digest: ActivityDigest }`
- Card titled "Last 24 Hours"
- Three stat items in a grid (3 cols on md, 1 on mobile):
  - Messages: `digest.messagesSent` with MessageSquare icon
  - Safety Events: `digest.safetyEventsDetected` with AlertTriangle icon (yellow if > 0)
  - Active Children: `digest.activeChildren` with Users icon
- System health badge at bottom: green "Healthy" / yellow "Warning" / red "Critical"

**`RecentAlertsCard`** (TRUST-03):
- Props: `{ alerts: RecentAlert[] }`
- Card titled "Recent Safety Alerts"
- If no alerts: show a green message "No safety events detected recently"
- If alerts exist: list each with type badge (destructive for jailbreak, yellow for redirect), child name, truncated excerpt, relative time
- Footer: Link component pointing to `/alerts` with "View all alerts" text and ArrowRight icon
- Use `next/link` for the link
