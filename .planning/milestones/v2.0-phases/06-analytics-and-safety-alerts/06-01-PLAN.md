  <action>
1. Install recharts: `npm install recharts`

2. Create GET /api/analytics with auth guard (same pattern as conversations API).

The API should return three datasets from MongoDB aggregations on the `messages` collection:

**a) Messages per day (last 30 days):**
- Aggregate messages grouped by date (YYYY-MM-DD format) and by user (join with users collection via conversations.user)
- Use $lookup from messages -> conversations (on conversationId) to get the user field, then $lookup from conversations -> users (string userId to ObjectId _id using $toString pattern from existing code)
- Return array: `{ date: string, total: number, children: { [childName: string]: number } }`
- Fill in zero-count days so the chart has no gaps

**b) Active hours:**
- Aggregate messages by hour of day (0-23) and by child
- Return array: `{ hour: number, total: number, children: { [childName: string]: number } }`
- All 24 hours present (zero-fill)

**c) Preset usage:**
- Aggregate conversations grouped by `chatGptLabel` field (this stores the preset name like "Friendly Tutor")
- Join with users to get child name
- Return array: `{ preset: string, total: number, children: { [childName: string]: number } }`
- Filter out null/empty chatGptLabel values

**d) Quick summary stats for the response:**
- totalMessages (last 30 days)
- totalConversations (last 30 days)
- mostActiveChild (name of child with most messages in last 30 days)

Return JSON: `{ messagesPerDay: [...], activeHours: [...], presetUsage: [...], summary: { totalMessages, totalConversations, mostActiveChild } }`

Only count messages where isCreatedByUser is true OR false (include both sides) for messages-per-day and active-hours. For preset usage, count conversations (not messages).

Filter only non-admin users for child stats (join with users and filter role !== "ADMIN").
