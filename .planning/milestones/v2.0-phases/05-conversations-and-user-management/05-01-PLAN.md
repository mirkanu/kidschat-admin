  <name>Task 1: Conversations API route</name>
  <files>src/app/api/conversations/route.ts</files>
  <action>
Create GET /api/conversations that queries MongoDB and returns conversations joined with user names.

Implementation:
- Import getMongoClient from "@/lib/mongodb" and auth from "@/auth"
- Check auth(); return 401 if no session
- Accept query params: `search` (string, optional), `child` (string — "all" | "sebastian" | "penelope", default "all")
- MongoDB aggregation pipeline on "conversations" collection in "test" database:
  1. $lookup: join users collection on `user` field (ObjectId string) matching users._id — BUT `conversations.user` is stored as a string (userId), not ObjectId. Use $addFields to cast or match as string. The `user` field in conversations holds the userId as a plain string.
  2. $unwind: $users (preserve nulls to handle orphaned conversations)
  3. If `child` filter is "sebastian" or "penelope": $match on users.name containing the name (case-insensitive regex)
  4. If `search` is provided: $match on title with case-insensitive regex
  5. $sort: { updatedAt: -1 } (newest first)
  6. $limit: 100
  7. $project: { conversationId: 1, title: 1, updatedAt: 1, createdAt: 1, userName: "$users.name", userEmail: "$users.email" }

Return JSON: `{ conversations: ConversationSummary[] }`

Type to define inline:
```typescript
interface ConversationSummary {
  conversationId: string
  title: string
  updatedAt: string
  userName: string | null
  userEmail: string | null
}
```

Note: The lookup needs to match conversations.user (string) against users._id (ObjectId). Use:
```
{ $lookup: { from: "users", let: { userId: "$user" }, pipeline: [{ $match: { $expr: { $eq: [{ $toString: "$_id" }, "$$userId"] } } }], as: "userInfo" } }
```
Then $unwind "$userInfo" with preserveNullAndEmptyArrays: true, then $project userName from userInfo.name.
