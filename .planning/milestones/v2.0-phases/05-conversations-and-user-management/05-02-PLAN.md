Create GET /api/conversations/[conversationId] that returns all messages for a conversation in chronological order.

Implementation:
- Import getMongoClient from "@/lib/mongodb" and auth from "@/auth"
- Check auth(); return 401 if no session
- Extract conversationId from params (Next.js 15: `const { conversationId } = await params`)
- Query messages collection: `db.collection("messages").find({ conversationId }).sort({ createdAt: 1 }).toArray()`
- Also fetch conversation metadata: `db.collection("conversations").findOne({ conversationId })` to get the title
- Return JSON:
```typescript
{
  conversation: {
    conversationId: string
    title: string
  }
  messages: MessageItem[]
}

interface MessageItem {
  messageId: string
  text: string
  isCreatedByUser: boolean
  sender: string
  createdAt: string // ISO string
}
```
- Map over messages, convert _id and createdAt to strings (createdAt.toISOString() if it's a Date, or toString() if already a string)
- Return 404 if conversation not found
