Conversion math (eurToTokens):
- LibreChat's tokenCredits is a unitless integer where 1 credit ≈ 1 input token for Haiku
- Haiku 4.5 input cost: ~$1/M tokens → €0.92/M tokens
- So 1 eur ≈ ~1_087_000 credits (inverse of 0.92/M)
- Formula: `eurToTokens(eur) = Math.round(eur / 0.92 * 1_000_000)` — tune the exact ratio by reading `USD_TO_EUR_RATE` env var if present, else default 0.92
- Record the exact formula + constants as an exported comment block
