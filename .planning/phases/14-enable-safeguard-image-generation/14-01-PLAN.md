  <name>Task 1: Set Railway env vars for DALL-E 3</name>
  <files>(Railway env vars — no local files)</files>
  <action>
Using Railway CLI, set the following env vars on the LibreChat service:

1. **DALLE3_API_KEY**: Set to the same value as any existing OPENAI_API_KEY. If no OPENAI_API_KEY exists, the user must provide an OpenAI API key.
   - First check: `railway variables --service librechat | grep OPENAI_API_KEY` (or equivalent)
   - If exists: `railway variables set DALLE3_API_KEY=$OPENAI_API_KEY_VALUE --service librechat`
   - If not: prompt user for OpenAI API key

2. **DALLE3_SYSTEM_PROMPT**: Set to the following child-safety guidance:
   ```
   You help children ages 10-14 create wholesome illustrations and drawings.

   When a child asks you to draw something:
   - Only create age-appropriate, wholesome illustrations — animals, nature, fantasy creatures, Bible scenes, everyday life, abstract art
   - Refuse requests for violence, horror, scary monsters, weapons, immodest content, or real people
   - Frame it as "drawing" or "illustrating" rather than "generating an image" — this matches how children think
   - If a request is borderline, redirect warmly: "Let's draw something even better — how about [wholesome alternative]?"
   - Use simple, clear language in your image prompts to avoid content filter false positives

   If asked to draw something inappropriate, say: "I only draw wholesome things! How about I draw [cheerful alternative] instead?"
   ```

3. **Verify** DALLE2_API_KEY is NOT set (ensuring DALL-E 2 is disabled):
   - Check: `railway variables --service librechat | grep DALLE2`
   - If set, remove it.

Important: Do NOT set DALLE_REVERSE_PROXY or any other DALL-E env vars. Only DALLE3_API_KEY and DALLE3_SYSTEM_PROMPT.
  </action>

When a child asks you to draw, use the DALL-E tool to create the image. If a request is inappropriate (violence, horror, immodest content, real people), decline warmly and suggest a wholesome alternative. Keep your responses short, friendly, and encouraging."
5. Save the agent and note the agent_id from the URL or agent details (format: agent_XXXXXXXXXXXXXXXX)
6. Share the agent (make it available to all users)
7. Report back with the agent_id value

<task type="auto">
  <name>Task 3: Update librechat.yaml with Drawing modelSpec and deploy</name>
  <files>.planning/phases/02-safety-configuration/librechat.yaml</files>
  <action>
After receiving the agent_id from Task 2, update the local librechat.yaml and deploy it via the Gist editor API.

1. **Update interface section** — change `agents: false` to:
   ```yaml
   agents:
     use: true
     create: false
     share: false
     public: false
   ```
   This allows users to USE agents (access the Drawing preset) but not create/modify/share their own agents.

2. **Add Drawing modelSpec** — append to the existing `modelSpecs.list` array (after the Standard Formal preset):
   ```yaml
   # ---- PRESET 5: KidsChat Drawing (DALL-E 3) ----
   # Agent ID from LibreChat Agent Builder — if agent is recreated, update this ID
   - name: kidschat-drawing
     label: "KidsChat Drawing"
     description: "Ask me to draw something! I make wholesome illustrations."
     default: false
     preset:
       endpoint: "agents"
       agent_id: "AGENT_ID_FROM_TASK_2"
       greeting: "Hi! I'm your drawing helper. Tell me what you'd like me to draw — animals, scenes, fantasy creatures, Bible stories — and I'll illustrate it for you!"
   ```

3. **Deploy via Gist** — use the existing Phase 12 deploy API to push the updated librechat.yaml:
   - Read the full updated YAML file
   - POST to the admin dashboard deploy endpoint: `https://kidschat-admin-production.up.railway.app/api/prompt-editor/deploy` with the updated YAML content
   - OR use the admin dashboard Prompt Editor UI to deploy

4. **Trigger LibreChat redeploy** on Railway so it picks up the new env vars and config:
   - `railway up --service librechat` or trigger redeploy via Railway CLI

Important anti-patterns to AVOID:
- Do NOT put image guidance in the modelSpec's promptPrefix — DALL-E only sees DALLE3_SYSTEM_PROMPT, not promptPrefix
- Do NOT use `endpoint: "gptPlugins"` — deprecated since v0.7.5
- Do NOT set `interface.agents: true` (boolean) — use the object form with create/share/public: false
  </action>
