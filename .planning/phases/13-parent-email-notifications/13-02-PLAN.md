  <behavior>
    - getWeeklyChildStats(db) returns array of WeeklyChildStats objects
    - Each WeeklyChildStats has: name (string), totalMessages (number >= 0), activeDays (number 0-7), topPresets (string[])
    - Only non-ADMIN users appear in results
    - Stats cover exactly the last 7 days
    - Empty result set returns empty array (not null/undefined)
  </behavior>
  <action>
    1. Create `src/lib/weekly-digest.ts`:
       - Export interface `WeeklyChildStats { name: string; totalMessages: number; activeDays: number; topPresets: string[] }`
       - Export async function `getWeeklyChildStats(db: Db): Promise<WeeklyChildStats[]>`
       - Implementation: MongoDB aggregation pipeline (based on research Pattern 5):
         a. Match messages from last 7 days where `isCreatedByUser: true`
         b. Lookup conversations to get `user` field and `chatGptLabel` (preset)
         c. Lookup users to get `name` and `role`
         d. Filter out ADMIN users (`userInfo.role !== "ADMIN"`)
         e. Group by user name: count messages, collect distinct days (`$addToSet` on date string), collect distinct presets (`$addToSet` on `chatGptLabel`)
         f. Project to WeeklyChildStats shape: `activeDays` = length of distinct days array, `topPresets` = array of preset labels (max 5)
       - Handle edge cases: missing user name defaults to "Unknown Child", null chatGptLabel excluded from presets

    2. Create `src/lib/__tests__/weekly-digest.test.ts`:
       - Since this needs MongoDB, test the TYPE SHAPE contract rather than live queries:
         a. Test that WeeklyChildStats interface matches expected shape (use a mock object and type-check)
         b. Test a helper function `formatDigestStats(raw)` that transforms raw aggregation results into the final shape
         c. Extract the transform logic into a testable pure function in weekly-digest.ts
       - Also test the notification record shape: `{ type: "weekly_digest", sentAt: Date, to: string[], weekOf: string, resendId: string, meta: object }`
  </action>
