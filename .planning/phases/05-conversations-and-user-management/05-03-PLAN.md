Create API routes for listing, creating, editing, and deleting user accounts.

**src/app/api/users/route.ts**:

GET handler:
- Check auth(); return 401 if no session
- Query: `db.collection("users").find({}, { projection: { password: 0 } }).sort({ createdAt: -1 }).toArray()`
- Map results: convert _id to string, format createdAt/updatedAt as ISO strings
- Return `{ users: UserSummary[] }` where:
```typescript
interface UserSummary {
  id: string; name: string; email: string;
  role: "ADMIN" | "USER"; lastActive: string | null; createdAt: string;
}
```
- lastActive = updatedAt?.toISOString() ?? null

POST handler:
- Check auth(); return 401 if no session
- Parse body: `{ name, email, password, role }` — validate all present, role must be "ADMIN" or "USER"
- Check email uniqueness: `db.collection("users").findOne({ email })` — return 409 if exists
- Hash password: `await bcryptjs.hash(password, 12)`
- Insert: `db.collection("users").insertOne({ name, email, username: email.split("@")[0], password: hashedPassword, role, emailVerified: false, createdAt: new Date(), updatedAt: new Date() })`
- Return 201 with `{ user: { id, name, email, role } }`

**src/app/api/users/[userId]/route.ts**:

PATCH handler (edit user):
- Check auth(); return 401 if no session
- Extract userId from params (Next.js 15: `const { userId } = await params`)
- Parse body: `{ name?, role?, password? }` — at least one required
- Build $set object: include name and role if provided
- If password provided: hash it and add `password: hashedPassword` to $set
- Always add `updatedAt: new Date()` to $set
- Update: `db.collection("users").updateOne({ _id: new ObjectId(userId) }, { $set })`
- Return 200 with `{ success: true }` or 404 if no document matched

DELETE handler:
- Check auth(); return 401 if no session
- Extract userId from params
- Prevent self-deletion: get session, if session.user.id === userId return 400 with `{ error: "Cannot delete your own account" }`
- Delete: `db.collection("users").deleteOne({ _id: new ObjectId(userId) })`
- Return 200 with `{ success: true }` or 404 if not found

Import ObjectId from "mongodb": `import { ObjectId } from "mongodb"`

On submit for edit: PATCH /api/users/{user.id} with only changed fields ({ name, role } always; password only if not empty)
Call onSuccess with the updated/created user, then onClose.
