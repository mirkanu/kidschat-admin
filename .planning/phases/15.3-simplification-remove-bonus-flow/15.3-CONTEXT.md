# Phase 15.3 — Simplification: Remove Bonus Flow & Custom Warnings

## Why this phase exists

Phase 15.2 attempted to fix the "invisible synthetic messages" bug via Option 7 (agent system prompt context injection). The root cause was correctly identified (LibreChat's React Query cache `refetchOnMount: false`) and the implementation shipped. But live UAT with Manuel never rendered the injected text visibly in an active session, despite the agent compliance probe (Task 1) succeeding.

Rather than chase a 5th fix, the user decided to **delete the entire custom warning + bonus flow** and rely on LibreChat's native "Insufficient Funds" hard block. A short research pass confirmed LibreChat has no native alternative:

- **No native low-balance warning** (`TokenCreditsItem.tsx` only shows raw number; no threshold logic)
- **No per-user auto-refill** (`createSetBalanceConfig` middleware forcibly syncs global config to every user on every request)
- **No admin balance UI** (admins must manipulate mongo directly)

So the trade-off is: we lose soft warnings and the self-service bonus unlock, but we gain a system that's ~800 LOC lighter, has zero injection magic, and works with vanilla LibreChat.

## Final architecture

**Kid-facing experience:**
- Chat up to their per-child daily cap
- When tokenCredits hits 0 → LibreChat's native red "Insufficient Funds" block
- Balance visible in LibreChat Settings (native)
- **No warnings, no bonus offers, no YES flow**

**Parent-facing (admin):**
- `/settings` — global daily/monthly cap + per-child override table (already works, keep as-is, remove bonusPack + weeklyBonusCap fields)
- `/users/{userId}` — 2-bar usage (daily/monthly €) (already works)
- `/users/{userId}` — **NEW:** "Top up €0.10" button → server action → direct `$inc balances.tokenCredits` by `eurToTokens(0.10)` → refresh shows new balance
- Dashboard home "spend per child" overview card (already works)

**Backend:**
- `daily-reset` cron at 00:00 UTC → `topUpDailyBudget` per child (already works)
- `monthly-reset` cron on 1st at 00:00 UTC → `topUpMonthlyBudget` per child (already works)
- LibreChat handles enforcement via native `checkBalance` middleware
- **No custom polling listener, no injection, no delivery detection, no TTL sweep**
