<interfaces>

**Tool the MCP server exposes to LibreChat:**
```json
{
  "name": "image_search",
  "description": "Search the web for safe, kid-appropriate images. Returns thumbnail URLs only — no source-site links.",
  "inputSchema": {
    "type": "object",
    "properties": {
      "query": { "type": "string", "description": "Search query text" },
      "count": { "type": "integer", "minimum": 1, "maximum": 12, "default": 10 }
    },
    "required": ["query"]
  }
}
```

**Tool response shape (normalized across both providers):**
```json
{
  "images": [
    {
      "thumbnail": "https://…/thumb.jpg",
      "title": "origami cat tutorial",
      "source_domain": "example.com",
      "provider": "google-cse" | "openverse",
      "license": "cc-by-2.0" // openverse only; omitted for google-cse
    }
  ],
  "provider_used": "google-cse" | "openverse" | "google-cse-then-openverse"
}
```

**Google CSE request (primary):**
```
GET https://www.googleapis.com/customsearch/v1?
    key=$GOOGLE_CSE_KEY&
    cx=$GOOGLE_CSE_CX&
    q=<query>&
    searchType=image&
    safe=active&
    num=10
```

**Openverse request (fallback):**
```
GET https://api.openverse.org/v1/images/?q=<query>&page_size=10
```
(No auth. No SafeSearch flag — Openverse content is already CC-curated.)

**Fallback logic in server.ts:**
1. Try Google CSE. If response.items?.length > 0, return them.
2. If Google returns 0 items OR HTTP 429 (daily-cap exceeded) OR HTTP 5xx, call Openverse.
3. If Openverse also fails, return `{ images: [], provider_used: null, error: "both_failed" }`.

**Transport expected by LibreChat v0.8.4 librechat.yaml:**
```yaml
mcpServers:
  image-search:
    type: streamable-http
    url: "${IMAGE_SEARCH_MCP_INTERNAL_URL}"
    startup: true
    chatMenu: false
```

**Click-through policy enforcement at tool boundary (option iii):**
The server never returns source site URLs — only `thumbnail`, `title`, `source_domain` (for attribution display only), and `provider`. The agent cannot leak a clickable source link because the tool schema prevents it.

       - Constructs URL: `https://www.googleapis.com/customsearch/v1?key=<key>&cx=<cx>&q=<encodeURIComponent(query)>&searchType=image&safe=active&num=<min(count,10)>`

       - `fetch` it. Normalize `results[].thumbnail` → `thumbnail`, `results[].title` → `title`, `results[].source` → `source_domain`, `results[].license` → `license` (openverse-only).

       - Import `@modelcontextprotocol/sdk` server + HTTP transport.
       - Register one tool `image_search` with schema from `<interfaces>`.
       - Tool handler logic:
         ```ts
         try {
           const g = await searchGoogleImages(query, count);
           if (g.images.length > 0) return { ...g, provider_used: "google-cse" };
           // Fall through on empty Google results
           const o = await searchOpenverseImages(query, count);
           return { ...o, provider_used: "google-cse-then-openverse" };
         } catch (e) {
           if (e instanceof ProviderRateLimitedError || e instanceof ProviderServerError) {
             const o = await searchOpenverseImages(query, count);
             return { ...o, provider_used: "openverse" };
           }
           throw e;
         }
         ```
