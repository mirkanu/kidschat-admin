## Rationale

- Old URLs: `unpkg.com/lucide-static` serves raw SVGs with `stroke="currentColor"`. On LibreChat's dark sidebar, `currentColor` resolves to a dark/black value, making icons nearly invisible.
- New URLs: Iconify API (`api.iconify.design`) supports a `?color=` query parameter that bakes the stroke color directly into the SVG. Color `#e2e8f0` (Tailwind slate-200) renders as a light gray, clearly visible on dark backgrounds.
- No other config changes were made — no schema keys added or removed.
