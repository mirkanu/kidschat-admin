1. **Create src/lib/safety-patterns.ts:**

Export a type and detection function:

```typescript
export interface SafetyEvent {
  type: 'safety_redirect' | 'jailbreak_attempt';
  conversationId: string;
  conversationTitle: string;
  childName: string;
  messageText: string;       // Truncated excerpt (first 150 chars)
  detectedAt: string;        // ISO timestamp of the message
  matchedPattern: string;    // Which pattern triggered the detection
}
```

**Safety redirect detection** (scan AI responses where isCreatedByUser=false):
Detect phrases indicating the AI safety prompt activated. Use case-insensitive regex matching. Patterns to match (AI response text):
- "I can't help with that"
- "I'm not able to"
- "not appropriate for"
- "let's talk about something else"
- "let's redirect"
- "beyond what I should discuss"
- "I need to decline"
- "against my guidelines"
- "I'm designed to"
- "as a safe AI"

**Jailbreak attempt detection** (scan user messages where isCreatedByUser=true):
Detect phrases indicating the child tried to bypass safety rules. Patterns to match (user message text):
- "ignore your instructions"
- "ignore previous instructions"
- "pretend you are"
- "pretend you have no"
- "act as if you have no rules"
- "you are now"
- "forget everything"
- "forget your rules"
- "new persona"
- "DAN" (case-sensitive, word boundary: \bDAN\b)
- "roleplay as someone without"
- "jailbreak"
- "bypass your"
- "override your"
- "disregard your"

Export function `detectSafetyEvent(text: string, isCreatedByUser: boolean): { detected: boolean; type: SafetyEvent['type'] | null; matchedPattern: string | null }` that checks a single message against the appropriate patterns.

2. **Create GET /api/alerts:**
   - Auth guard (same pattern as other APIs)
   - Query MongoDB messages collection for last 90 days (broader window than analytics)
   - For each message, run detectSafetyEvent
   - For detected events, join with conversations collection to get title and userId, then join with users to get child name
   - Strategy: Use MongoDB aggregation to first get recent messages, then process in JS (pattern matching is not practical in MongoDB regex aggregation across all patterns)
   - Efficient approach:
     a. Fetch all messages from last 90 days (limit 5000 to prevent memory issues)
     b. Run pattern detection in JS
     c. For matches, batch-lookup conversation metadata and user names
   - Sort results by detectedAt descending (newest first)
   - Return JSON: `{ alerts: SafetyEvent[], totalCount: number }`
   - Support optional `?days=N` query param (default 90)
