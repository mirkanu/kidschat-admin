<objective>
Fix the misleading budget.ts documentation, raise the default daily cap to a realistic value, and correct the wildly wrong SYSTEM_PROMPT_TOKENS constant so admin dashboard cost estimates reflect reality.

Purpose: Research Area 1 showed the math in budget.ts is correct but the mental model the comments document is wrong (says "1 credit ≈ 1 input token" without mentioning output tokens cost 5 credits each). Area 3 showed SYSTEM_PROMPT_TOKENS=400 is 8x too low — actual agent-call overhead is ~3,290 tokens. Area 1 remediation says 0.50 EUR/day is the minimum realistic cap. Changing HARDCODED_DEFAULTS alone is not enough — the live MongoDB doc must also be updated or per-child overrides must be set (per STATE.md, admin already raised DB to 0.20; we need 0.50).

Output: Three source files updated + one MongoDB doc updated + a unit-test smoke check that per-child overrides still take precedence.
</objective>
