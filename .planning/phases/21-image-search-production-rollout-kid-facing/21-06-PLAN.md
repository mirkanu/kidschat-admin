<objective>
Close **OVERSIGHT-03** by adding per-child image-search visibility to the daily-summary email:
1. **Image searches count** line ("Image searches: N") always rendered on every active kid's card — parallel to the existing "Alerts: N" line.
2. **Haiku-paraphrased summary** of the day's queries when N > 0 (e.g. "Penelope searched for animals, art projects, and science experiments.") — matches the paraphrase-only privacy contract from quick task 260417-p94.

Data source: `conversations` + `messages` collections filtered by `conversations.spec === "image-search"` + userId + 24h window. NO new collection. NO new cron. Bolt-on to the existing `/api/notify/daily-summary` route that already runs at 08:00 UTC.

Why NOT query `search_counters`: the `daily-reset` cron at 00:00 UTC wipes `search_counters.deleteMany({})` before the 08:00 UTC daily-summary runs — by the time we'd read it, it's always zero. Querying `conversations`+`messages` directly is the only source of truth for yesterday's queries.

Why pulled into Phase 21 (from Phase 22): user decision 2026-04-21 — OVERSIGHT-03 is self-contained, doesn't depend on Test Mode, and belongs in the "parent oversight" cluster alongside OVERSIGHT-01/02 already in Phase 21. Phase 22 keeps only the Test Mode requirements.

Purpose: The parent's 08:00 UTC daily digest is the one place every day where the parent sees what their kids did; image-search activity must be visible there, not only in /conversations or /alerts.
Output: Next 08:00 UTC daily-summary email (or manual POST trigger) contains the "Image searches: N" line per kid + paraphrased one-sentence summary when N > 0, verified in parent inbox.
</objective>

    1. Create `src/lib/image-search-summary.ts`:

       ```typescript
       import type { Db } from "mongodb";

       export interface ImageSearchStats {
         count: number;
         /** Most-recent-first, deduplicated, capped at 5, each string capped at 200 chars. */
         queries: string[];
       }

       /**
        * Aggregate yesterday's image-search activity for one child.
        * Filter: conversations.spec === "image-search" AND conversations.user → users._id → users.name === childName.
        * Window: messages.createdAt >= (now - 24h), messages.isCreatedByUser === true.
        */
       export async function getImageSearchStats(
         childName: string,
         db: Db,
       ): Promise<ImageSearchStats> {
         const oneDayAgo = new Date();
         oneDayAgo.setDate(oneDayAgo.getDate() - 1);

         const rows = await db
           .collection("messages")
           .aggregate<{ text: string; createdAt: Date }>([
             { $match: { createdAt: { $gte: oneDayAgo }, isCreatedByUser: true } },
             { $lookup: { from: "conversations", localField: "conversationId", foreignField: "conversationId", as: "conv" } },
             { $unwind: { path: "$conv", preserveNullAndEmptyArrays: false } },
             { $match: { "conv.spec": "image-search" } },
             {
               $lookup: {
                 from: "users",
                 let: { userId: "$conv.user" },
                 pipeline: [{ $match: { $expr: { $eq: [{ $toString: "$_id" }, "$$userId"] } } }],
                 as: "userInfo",
               },
             },
             { $unwind: { path: "$userInfo", preserveNullAndEmptyArrays: false } },
             { $match: { "userInfo.name": childName } },
             { $project: { text: 1, createdAt: 1 } },
             { $sort: { createdAt: -1 } },
             // NB: no $limit here — we need the total count as well.
           ])
           .toArray();

         const count = rows.length;

         // Dedupe by exact text, preserve order (most-recent first), cap to 5, trim each to 200 chars.
         const seen = new Set<string>();
         const queries: string[] = [];
         for (const r of rows) {
           const raw = typeof r.text === "string" ? r.text : "";
           if (!raw || seen.has(raw)) continue;
           seen.add(raw);
           queries.push(raw.length > 200 ? raw.slice(0, 200) + "…" : raw);
           if (queries.length >= 5) break;
         }

         return { count, queries };
       }
       ```

    2. In `src/lib/ai-summary.ts`, append:

       ```typescript
       const IMAGE_SEARCH_QUERIES_SYSTEM_PROMPT = `You are summarising a child's image-search queries for a parent's daily digest. Output exactly one sentence that paraphrases the themes or topics the child searched for. Never quote a query verbatim — parents receive topic signals, not the raw words. Keep the whole output under 50 words. If queries touch sensitive topics (body/health, fears, social conflict, real people), name the topic gently so the parent can check in.`;

       /**
        * Summarise a child's image-search queries from the last 24h into one short sentence.
        *
        * @throws on missing ANTHROPIC_API_KEY, SDK error, 10s timeout, or empty response.
        * Caller must wrap in try/catch — identical contract to summarizeChildDay.
        */
       export async function summarizeImageSearchQueries(
         childName: string,
         queries: string[],
       ): Promise<string> {
         const Anthropic = (await import("@anthropic-ai/sdk")).default;
         const client = new Anthropic();

         const userMessage = `Child: ${childName}\nQuery count: ${queries.length}\nRecent queries (most-recent first, up to 5):\n${queries.map((q, i) => `${i + 1}. ${q}`).join("\n")}`;

         const resp = await client.messages.create(
           {
             model: "claude-haiku-4-5-20251001",
             max_tokens: 60,
             system: IMAGE_SEARCH_QUERIES_SYSTEM_PROMPT,
             messages: [{ role: "user", content: userMessage }],
           },
           { signal: AbortSignal.timeout(10_000) },
         );

         const text = resp.content
           .map((b) => (b.type === "text" ? b.text : ""))
           .join("")
           .trim();

         if (!text) throw new Error("Empty Anthropic response");
         return text;
       }
       ```
