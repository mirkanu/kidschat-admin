**1. `getSystemStatus()`** — Returns safety system health (TRUST-01)
```typescript
export interface SystemStatus {
  allSystemsActive: boolean;
  lastChecked: string; // ISO timestamp
  systems: Array<{
    name: string;
    status: "active" | "degraded" | "down";
    detail: string;
  }>;
}
```
Implementation:
- Check MongoDB connectivity by running `db.command({ ping: 1 })` — if it responds, MongoDB is active
- Check that users exist (at least 1 admin account) — query `db.collection("users").countDocuments({ role: "ADMIN" })`
- Check that safety patterns are loaded by importing `detectSafetyEvent` from `@/lib/safety-patterns` and verifying it's callable (always true at runtime, but confirms the module loaded)
- Return systems array with 3 items: "MongoDB Database" (ping result), "User Accounts" (admin count > 0), "Safety Pattern Detection" (always active)
- `allSystemsActive` = all systems have status "active"
- `lastChecked` = `new Date().toISOString()`

**2. `get24hDigest()`** — Returns 24-hour activity summary (TRUST-02)
```typescript
export interface ActivityDigest {
  period: "24h";
  messagesSent: number;
  safetyEventsDetected: number;
  activeChildren: number;
  systemHealth: "healthy" | "warning" | "critical";
}
```
Implementation:
- Calculate cutoff: `new Date(Date.now() - 24 * 60 * 60 * 1000)`
- `messagesSent`: `db.collection("messages").countDocuments({ createdAt: { $gte: cutoff } })`
- For `safetyEventsDetected`: query messages from last 24h (limit 2000), run each through `detectSafetyEvent()`, count matches. Reuse the same pattern from alerts/page.tsx but scoped to 24h.
- `activeChildren`: count distinct user IDs from messages in last 24h where `isCreatedByUser: true`. Use `db.collection("messages").distinct("user", { createdAt: { $gte: cutoff }, isCreatedByUser: true })` and get the array length.
- `systemHealth`: "healthy" if no jailbreak attempts in 24h, "warning" if any safety events exist, "critical" if more than 5 jailbreak attempts

**3. `getRecentAlerts(limit = 5)`** — Returns recent safety alerts for dashboard preview (TRUST-03)

```typescript
export interface RecentAlert {

  messageExcerpt: string;

  conversationId: string;

```

- After detecting, take only the first `limit` results (already sorted newest first)
- Map to `RecentAlert` (simplified version of SafetyEvent — no conversationTitle, no matchedPattern)
- Include user name lookup (same $lookup pattern as alerts page)

Import `getMongoClient` (default import) from `@/lib/mongodb` and `detectSafetyEvent` + `SafetyEvent` type from `@/lib/safety-patterns`.
