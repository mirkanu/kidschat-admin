**One-liner:** Agent system-prompt injection (Option 7) delivers budget warnings and bonus offers inline via LibreChat's native SSE pipeline, bypassing the React Query `refetchOnMount: false` cache staleness root cause.

## Probe Outcome

**Result:** GO — Option 7 validated.

The Friendly Tutor agent delivered the probe marker (`PHASE-15.2-PROBE-OK`) verbatim as the first line of its reply, followed by a blank line and its normal response. No rephrasing, wrapping, or preamble.

**Key field path correction:** The plan assumed `model_options.system`. The live agent document stores its system prompt in a top-level `instructions` field. Agent documents are queried by `{id: agentId}` (not `{agent_id: agentId}`).

## Implementation (GO Branch)

### sendBonusOfferMessage (bonus-delivery.ts)

Rewritten to:
1. Read `agents.instructions` for the target agent (query: `{id: agentId}`)
2. Store original in `balance_state.originalAgentInstructions` (idempotent — only on first call)
3. Prepend a verbatim-delivery instruction prefix to the instructions
4. Write modified instructions back to `agents.instructions`
5. Set `balance_state.pendingWarning = { messageTemplate, injectedAt, agentId, agentObjectId }`
6. Return `uuidv4()` as messageId — **no insert into `messages` collection**

### restoreAgentSystemPrompt (bonus-delivery.ts)

New exported function:
- Reads `balance_state.originalAgentInstructions` + `pendingWarning.agentId`
- Writes original back to `agents.instructions`
- `$unset: { pendingWarning: "", originalAgentInstructions: "" }` on balance_state
- Idempotent: no-op if `pendingWarning` is null

### Delivery detection (change-stream-listener.ts)

In `processMessageEvent`, before YES detection:
- If `pendingWarning` exists AND kid message `createdAt > injectedAt + 5s` buffer
- Query for any AI message in that conversation with `createdAt > injectedAt`
- If found: call `restoreAgentSystemPrompt` → instructions restored, pendingWarning cleared

### TTL safety net (change-stream-listener.ts pollOnce)

At top of each 60s tick:
- Query `balance_state` for `pendingWarning.injectedAt < now - 10min`
- For each stuck doc: call `restoreAgentSystemPrompt` → force-restore
