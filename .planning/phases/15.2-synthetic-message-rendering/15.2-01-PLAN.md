<objective>
Fix the "invisible synthetic messages" bug via Option 7 (Agent System Prompt Context Injection) from 15.2-RESEARCH.md, with a UUID v4 messageId correction as baseline.

Purpose: Research empirically confirmed that LibreChat's React Query cache has `refetchOnMount: false`, so direct-inserted synthetic messages never appear in active sessions. The authoritative fix is to stop inserting raw docs into the `messages` collection and instead ride LibreChat's native SSE pipeline by temporarily prepending a delivery instruction to the target agent's `model_options.system`. We de-risk Option 7's MEDIUM-confidence assumption (that the agent reliably follows prepended instructions) with a one-shot empirical probe before committing to the full implementation.

Output: A single plan that (1) probes Option 7 viability, (2) implements Option 7 on GO or falls back to UUID-only fix on NO-GO, (3) resets Manuel's state for end-to-end UAT, and (4) captures human confirmation of visible delivery.
