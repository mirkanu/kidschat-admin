# Quick 260417-p94: Daily-Summary Email Overhaul

## What shipped

The daily-summary email (sent by `/api/notify/daily-summary` cron at 08:00 UTC) is overhauled per user request:

**Removed:**
- `imageRequests` count
- `topPresets` ("Presets Used")

**Added:**
- `alertCount` per child (always shown, even at 0)
- `alertSummary` AI-generated paraphrase of yesterday's safety alerts (when count > 0)
- `summary` AI-generated one-sentence paraphrase of yesterday's chats with optional `Concerns:` line

**Kept:**
- `totalMessages` count

## Architecture

```
/api/notify/daily-summary route
  ↓
getDailyChildStats(db)  ← src/lib/daily-summary.ts
  ↓ for each kid
  ├── totalMessages       (Mongo aggregation, unchanged)
  ├── alertCount          (Mongo: email_notifications type=safety_alert)
  └── conversationExcerpts (Mongo: messages joined to conversations + users, last 24h)
  ↓
parallel per-kid:
  summarizeChildDay(name, msgs, excerpts) → Haiku 4.5 → "<sentence>. Concerns: <...>"
  summarizeAlerts(name, alerts)            → Haiku 4.5 → "<one-sentence paraphrase>"
  ↓ (try/catch per kid; on failure: "(summary unavailable today)")
attach summary + alertSummary to stats
  ↓
DailySummaryEmail React template renders per-kid card
  ↓
Resend send + email_notifications insert (conversationExcerpts STRIPPED)
```
